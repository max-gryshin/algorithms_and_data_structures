📚 О задаче

Steiner Tree Problem — это NP-трудная задача оптимизации, которая заключается в поиске минимального по стоимости дерева, соединяющего заданный набор терминальных вершин, с возможностью использования дополнительных промежуточных вершин (узлов Steiner).

Параметры:

  • Терминальные узлы — обязательно соединить все
  • Узлы Steiner — опциональны, но могут снизить общую стоимость
  • Стоимость ребра — евклидово расстояние между узлами
  • Стоимость узла — фиксированная цена активации узла Steiner
🎯 Цель: Выбрать подмножество узлов Steiner и построить минимальное остовное дерево (MST) так, чтобы минимизировать суммарную стоимость = Cost(MST) + Cost(Steiner).

🤖 Гибридный алгоритм GA + MST

Верхний уровень: Генетический алгоритм

GA ищет оптимальное подмножество узлов Steiner, которое нужно активировать. Геном — это бинарный вектор длины M (количество опциональных узлов).

Нижний уровень: Алгоритм Крускала (MST)

Для каждого кандидата (набора активных узлов) Крускал мгновенно строит оптимальное дерево, используя переиспользуемый DSU (Disjoint Set Union).

Почему это работает: Нам не нужны сложные операторы скрещивания графов. MST гарантирует для любого набора узлов оптимальное дерево без циклов.

Фитнес-функция

$$\text{Fitness} = \text{Weight}(\text{MST}) + \sum (\text{Стоимость узлов})$$

Цель: минимизировать Fitness
