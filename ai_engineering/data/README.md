# Данные курса

- `corpus_ru.txt` — небольшой оригинальный русский текст (написан для курса, без авторских прав).
  Используется в тестах и примерах L2, L4, L5, L9. Достаточен для быстрых тестов, мал для серьёзного обучения.

Для обучения GoGPT (L9) на большем корпусе тексты скачиваются в момент запуска
(public domain, например Project Gutenberg / tiny shakespeare) — в репозиторий не кладутся и в тестах не используются:

```bash
go run ./ai_engineering/gpt/cmd/train -download shakespeare ...      # karpathy/char-rnn tinyshakespeare → data/downloads/
go run ./ai_engineering/gpt/cmd/train -download gutenberg:<id> ...   # книга Project Gutenberg (обрезаются заголовок/лицензия)
```

Скачанное (`downloads/`) и всё, что пишут запуски (`runs/`: `train.bin`/`val.bin`, `log.csv`, `model.ckpt`),
перечислено в `data/.gitignore`.

Правило для курса: **не воспроизводить в репозитории дословные отрывки опубликованных произведений** —
только оригинальные тексты или загрузка во время выполнения.

Файлы для L5 (токенизация):
- `parallel_ru.txt` — первые 5 абзацев `corpus_ru.txt`; `parallel_en.txt` — их перевод на английский
  (оригинальный текст курса). Параллельная пара нужна, чтобы честно сравнивать «стоимость» одного и того же
  смысла в токенах на разных языках.
- `code_go.txt` — снимок исходников пакета `ai_engineering/tensor` (зафиксирован, чтобы цифры в лекции не менялись).
