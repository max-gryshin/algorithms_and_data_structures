# L4. Нейронные сети: от нейрона до нейросетевой языковой модели

> **Цель лекции:** собрать из autograd и оптимизаторов (L3) настоящую нейросеть. Разберём нейрон и слой Linear,
> нелинейности (ReLU, tanh, GELU, SiLU) с их производными на числах, выведем правильную инициализацию весов
> (та же математика дисперсии, что и √d_k в L1) и увидим экспериментом, как неправильная инициализация убивает
> обучение. Затем — переобучение, weight decay, dropout, и **первая нейросетевая языковая модель**
> (Bengio et al., 2003), которая на нашем корпусе обгоняет биграммную модель из L2.
> Код: `ai_engineering/autograd` (тензорные операции), `ai_engineering/nn`, `ai_engineering/mlplm`.

---

## 1. Зачем это нужно

Биграммная модель из L2 знает только один предыдущий символ, и её «знания» — таблица счётчиков V × V.
Чтобы видеть контекст длиннее, таблица должна расти как Vⁿ: для 10 символов и V = 56 — 56¹⁰ ≈ 3·10¹⁷ ячеек.
Это **проклятие размерности**: почти все комбинации никогда не встречались в данных.

Нейросеть решает это иначе: вместо таблицы — **функция с обучаемыми параметрами**, которая обобщает.
Ключевая идея Bengio 2003: если модель выучила, что «кот сидит» и «пёс сидит» похожи, и представила «кот» и «пёс»
**близкими векторами**, то знание переносится на комбинации, которых она не видела. Это рождение **обучаемых
эмбеддингов** — тех самых, с которых начинается ваш конспект про трансформер.

Всё, что будет дальше (attention, FFN, GPT), — это слои, собранные из деталей этой лекции: Linear,
нелинейности, эмбеддинги, cross-entropy, AdamW.

## 2. Нейрон и слой Linear

### 🔍 Формула под лупой: один нейрон

$$z = \mathbf{x} \cdot \mathbf{w} + b = \sum_{i=1}^{n} x_i w_i + b, \qquad y = \phi(z)$$

| Символ | Смысл |
|---|---|
| **x** ∈ ℝⁿ | вход (например, эмбеддинг) |
| **w** ∈ ℝⁿ | веса нейрона — обучаемые |
| b | смещение (bias) — обучаемое число, «порог срабатывания» |
| z | «предактивация»: взвешенная сумма — скалярное произведение из L1 |
| φ | функция активации (нелинейность) |

**Пример:** x = [1, 2], w = [0.5, −0.3], b = 0.2: z = 0.5 − 0.6 + 0.2 = **0.1**; ReLU(0.1) = 0.1; tanh(0.1) = 0.0997.

Геометрически нейрон — «детектор направления» (L1, раздел 6): z велико, когда x смотрит туда же, куда w.

### Слой = много нейронов сразу = matmul

Сложим веса m нейронов **столбцами** в матрицу W (n × m), а смещения — в вектор **b** (m). Тогда все m нейронов
для всех B примеров считаются одной операцией:

$$Y = \phi(XW + \mathbf{b}), \qquad X: (B \times n),\; W: (n \times m),\; \mathbf{b}: (m) \;\Rightarrow\; Y: (B \times m)$$

**b** прибавляется к каждой строке через broadcasting (L1, 7.5), а его градиент — сумма по строкам (L3, раздел 5).
Это `nn.Linear`. Вход может иметь любые ведущие оси: (B, T, n)·(n, m) = (B, T, m) — одна матрица применяется к
каждому токену каждой последовательности (так устроены W_Q, W_K, W_V в трансформере).

## 3. Зачем нелинейность

### 🔍 Без нелинейности глубина бесполезна

Два линейных слоя подряд: (xW₁)W₂ = x(W₁W₂) — по ассоциативности это **один** линейный слой с матрицей W = W₁W₂.
Сколько бы слоёв ни было, сеть остаётся линейной функцией и может провести только «прямую границу».

**На числах:** W₁ = [[1, 2], [0, 1]], W₂ = [[1, 0], [3, 1]], W₁W₂ = [[7, 2], [3, 1]].
x = [1, 1]: xW₁ = [1, 3], ·W₂ = [1 + 9, 3] = **[10, 3]**; x·(W₁W₂) = [7 + 3, 2 + 1] = **[10, 3]** — то же самое.

Вставим ReLU между слоями, x = [−1, 1]:
- линейно: xW₁ = [−1, −1], ·W₂ = [−1 − 3, −1] = **[−4, −1]**;
- с ReLU: ReLU([−1, −1]) = [0, 0], ·W₂ = **[0, 0]**.

Нелинейность «изгибает» пространство: сеть Linear → φ → Linear с достаточно широким скрытым слоем может
приблизить **любую** непрерывную функцию (теорема об универсальной аппроксимации). Задача XOR из L3 линейно
неразрешима — её решает именно скрытый слой с tanh.

### Функции активации

| Имя | Формула | Производная | Где |
|---|---|---|---|
| **ReLU** | max(0, x) | 1 при x > 0, иначе 0 | классика CNN, простые MLP |
| **tanh** | (eˣ − e⁻ˣ)/(eˣ + e⁻ˣ) | 1 − tanh²x | RNN, наш MLP-LM (как у Bengio) |
| **sigmoid** σ | 1/(1 + e⁻ˣ) | σ(1 − σ) | гейты, вероятности |
| **GELU** | x·Φ(x) ≈ 0.5x(1 + tanh(√(2/π)(x + 0.044715x³))) | (сложная, см. код) | GPT-2, BERT |
| **SiLU / Swish** | x·σ(x) | σ(x)(1 + x(1 − σ(x))) | Llama (внутри SwiGLU, L8) |

Φ(x) — функция распределения стандартного нормального закона: «вероятность, что N(0,1) меньше x». GELU можно
читать как «пропустить x с вероятностью Φ(x)» — мягкая версия ReLU.

**Значения и производные (посчитано нашим кодом):**

| x | ReLU / ' | tanh / ' | σ / ' | GELU / ' | SiLU / ' |
|---|---|---|---|---|---|
| −2 | 0 / 0 | −0.964 / 0.071 | 0.119 / 0.105 | −0.045 / −0.086 | −0.238 / −0.091 |
| −1 | 0 / 0 | −0.762 / 0.420 | 0.269 / 0.197 | −0.159 / −0.083 | −0.269 / 0.072 |
| 0 | 0 / 0 | 0 / 1 | 0.5 / 0.25 | 0 / 0.5 | 0 / 0.5 |
| 1 | 1 / 1 | 0.762 / 0.420 | 0.731 / 0.197 | 0.841 / 1.083 | 0.731 / 0.928 |
| 2 | 2 / 1 | 0.964 / 0.071 | 0.881 / 0.105 | 1.955 / 1.086 | 1.762 / 1.091 |

Что важно увидеть:
1. **Насыщение tanh и sigmoid:** при |x| = 2 производная tanh всего 0.07. Градиент, проходя через насыщенный
   нейрон, умножается на ~0 (цепное правило!) — обучение глохнет. Тот же эффект, что у softmax без √d_k (L1).
2. **ReLU** не насыщается при x > 0 (производная ровно 1), но при x < 0 производная 0: если нейрон всегда получает
   отрицательный вход, он **«мёртв»** и никогда не оживёт.
3. **GELU и SiLU** — гладкие компромиссы: почти линейны при x > 0, пропускают немного градиента при x < 0
   (производная −0.09…0.07 вместо 0). Поэтому их используют в трансформерах.

Проверка производной tanh из таблицы L3: в x = 1, tanh = 0.762, 1 − 0.762² = 1 − 0.580 = **0.420** ✓.

## 4. Инициализация весов: снова дисперсия

С чего начинать обучение? Нулевые веса не подходят: все нейроны слоя будут считать одно и то же и получать
одинаковые градиенты — **симметрия** никогда не нарушится. Нужны случайные веса. Но **какого масштаба**?

### 🔍 Вывод: дисперсия выхода слоя

Нейрон: z = Σᵢ₌₁ⁿ xᵢwᵢ. Пусть xᵢ и wᵢ независимы, среднее 0, Var(xᵢ) = v_x, Var(wᵢ) = σ².
Точно как в выводе √d_k (L1, раздел 8):
- Var(xᵢwᵢ) = E[xᵢ²]·E[wᵢ²] = v_x·σ²;
- сумма n независимых слагаемых: **Var(z) = n · σ² · v_x**.

**Вывод:** каждый слой умножает дисперсию на n·σ². Через L слоёв — на (nσ²)ᴸ:
- nσ² > 1 — активации **взрываются** экспоненциально;
- nσ² < 1 — **затухают** экспоненциально;
- nσ² = 1, т.е. **σ = 1/√n** — дисперсия сохраняется. Это инициализация **LeCun**.

| Схема | σ² (дисперсия весов) | Для чего |
|---|---|---|
| LeCun | 1/n_in | линейные слои / tanh-подобные |
| Xavier (Glorot) | 2/(n_in + n_out) | компромисс: сохранить дисперсию и на forward (n_in), и на backward (n_out) |
| **He (Kaiming)** | **2/n_in** | ReLU: она обнуляет половину входов, значит E[ReLU(z)²] = Var(z)/2 — компенсируем множителем 2 |

Для tanh используют «усиление» (gain) 5/3: tanh сжимает сигнал, и gain это компенсирует.
В `nn.NewLinear(rng, in, out, bias, gain)` σ = gain/√in.

### Эксперимент: 10 слоёв по 256 нейронов, batch 512

Стандартное отклонение активаций после слоёв 1, 5, 10 (посчитано нашим autograd):

| Активация, σ весов | слой 1 | слой 5 | слой 10 | ‖∂L/∂W‖ (std): слой 1 / слой 10 |
|---|---|---|---|---|
| ReLU, σ = 1 | 9.4 | 1.5·10⁵ | **2.5·10¹⁰** 💥 | 10¹⁷ / 5·10¹⁷ |
| ReLU, σ = 0.01 | 0.094 | 1.5·10⁻⁵ | **2.5·10⁻¹⁰** 💀 | 10⁻²¹ / 5·10⁻²¹ |
| ReLU, σ = 1/√n (LeCun) | 0.59 | 0.14 | 0.023 | 1.3·10⁻⁶ / 6.9·10⁻⁶ |
| **ReLU, σ = √2/√n (He)** | **0.83** | **0.82** | **0.73** ✓ | 9.4·10⁻⁴ / 5.0·10⁻³ |
| tanh, σ = 1 | 0.97 | 0.97 | 0.97, но **89 %** нейронов насыщены (\|h\| > 0.97) | |
| **tanh, σ = (5/3)/√n** | **0.76** | **0.66** | **0.65** ✓, насыщено 5 % | |

Видно всё сразу:
- σ = 1 — взрыв в 10¹⁰ раз за 10 слоёв (при n = 256 множитель nσ²/2 = 128 на слой для ReLU);
- σ = 0.01 — сигнал исчезает; градиенты 10⁻²¹ — сеть не учится вообще;
- LeCun для ReLU — затухание примерно вдвое на слой (ровно потерянная ReLU «половина»);
- He — стабильно. Для tanh с σ = 1 дисперсия «не взрывается» только потому, что tanh ограничен ±1, но 89 %
  нейронов в насыщении — их градиент ≈ 0.

Это задача **vanishing / exploding gradients**. В трансформере (L8) её дополнительно решают **residual-связи**
(сигнал идёт «в обход» слоёв) и **нормализация** (LayerNorm/RMSNorm принудительно возвращают дисперсию к 1).

## 5. Обучение, обобщение, переобучение

### Train / validation / test

Цель — не запомнить обучающий текст, а хорошо предсказывать **новый**. Поэтому данные делят:
- **train** (~90 %) — на нём считаем градиенты;
- **validation** (~10 %) — только измеряем loss, чтобы выбирать гиперпараметры и момент остановки;
- **test** — смотрим один раз в самом конце (в нашем маленьком курсе часто совмещён с val).

### Переобучение на наших данных

Наш корпус `data/corpus_ru.txt` — 5 990 символов, V = 56. Обучим три модели (3 000 шагов, AdamW):

| Модель (контекст, эмбеддинг, скрытый слой) | Параметров | train loss | val loss |
|---|---|---|---|
| Биграммы со сглаживанием (L2) | 3 136 счётчиков | 2.39 | **2.41** |
| MLP: 3 символа, 10, 128 | 11 752 | 1.42 | **2.06** ✓ лучше биграмм |
| MLP: 5 символов, 10, 128 | 14 312 | 1.10 | 2.36 (лучшее — 2.33 на шаге 1000) |
| MLP: 8 символов, 16, 200 | 37 952 | **0.12** | **3.37** 💥 хуже биграмм |

Последняя модель почти **идеально выучила обучающий текст наизусть** (loss 0.12 ≈ 89 % уверенности в правильном
символе), но на новом тексте хуже даже биграмм: 38 тысяч параметров на 5 тысяч символов — модель запоминает,
а не обобщает. Это **переобучение (overfitting)**: train loss падает, val loss растёт.

```
 loss │╲
      │ ╲   val  ___----‾‾‾        ← переобучение: val растёт
      │  ╲____/
      │   ╲___
      │       ‾‾‾‾‾‾────── train
      └──────────────────────► шаги
             ↑ лучший момент (early stopping)
```

Средства против переобучения:
1. **Больше данных** — главное. LLM видят триллионы токенов и почти не переобучаются: каждый токен — один-два
   раза за всё обучение.
2. **Меньше модель / меньше контекст** — как в нашей таблице.
3. **Early stopping** — остановиться на минимуме val loss (у модели с 5 символами — шаг ≈ 1000).
4. **Weight decay** — L3, раздел 6.6: штраф за большие веса делает функцию «проще».
5. **Dropout** — ниже.

### 🔍 Формула под лупой: dropout

На обучении каждый элемент активации **обнуляется** с вероятностью p, а остальные **умножаются на 1/(1 − p)**:

$$\text{dropout}(x_i) = \begin{cases} 0, & \text{с вероятностью } p \\ x_i / (1-p), & \text{с вероятностью } 1-p \end{cases}$$

Деление на (1 − p) сохраняет **среднее**: E = (1 − p)·xᵢ/(1 − p) = xᵢ. Поэтому на инференсе dropout просто выключают.
**Пример:** p = 0.5, x = [2, 4, 6, 8], выпала маска [1, 0, 1, 0] → [4, 0, 12, 0] (сумма 16 вместо 20 — в среднем по
маскам 20). Смысл: сеть не может полагаться на конкретный нейрон, знание «размазывается». Градиент идёт только через
выжившие элементы, с тем же множителем. В современных LLM pretraining dropout часто **выключен** (p = 0) — данных
так много, что переобучения нет, — но при дообучении на малых данных он полезен. Функция `autograd.Dropout`.

## 6. Нейросетевая языковая модель (Bengio 2003)

### Архитектура и формы

```
 ids контекста           (B, N)        например N = 3 символа: «к», «о», «т»
        │  Embedding (V × D)
        ▼
 эмбеддинги              (B·N, D)      каждый символ → вектор из D = 10 чисел
        │  Reshape — «склейка» трёх векторов в один, без копирования (L1, 7.4)
        ▼
 x                       (B, N·D) = (B, 30)
        │  Linear 30 → 128, tanh
        ▼
 h                       (B, H) = (B, 128)
        │  Linear 128 → 56
        ▼
 логиты                  (B, V) = (B, 56)
        │  softmax + cross-entropy с настоящим следующим символом
        ▼
 loss                    скаляр
```

$$\text{logits} = \tanh\big(\text{concat}(E[c_1], \dots, E[c_N])\, W_1 + b_1\big)\, W_2 + b_2$$

| Символ | Форма | Смысл |
|---|---|---|
| E | V × D | матрица эмбеддингов — **обучается** вместе с остальным |
| E[cᵢ] | D | строка E для i-го символа контекста (lookup) |
| W₁, b₁ | N·D × H, H | скрытый слой |
| W₂, b₂ | H × V, V | «LM head»: балл каждого символа словаря |

**Параметров:** 56·10 + (30·128 + 128) + (128·56 + 56) = 560 + 3 968 + 7 224 = **11 752**.

### 🔍 Градиент эмбеддинга: scatter-add

Lookup E[c] — это умножение one-hot вектора на E (L0, L1): строка c «вырезается». Значит, градиент приходит **только
в строки использованных символов**, и если символ встретился несколько раз — вклады **складываются** (правило «+=»
из L3). Пример: E (3 × 2), ids = [2, 0, 2], L = сумма выхода → ∂L/∂E = [[1, 1], [0, 0], [2, 2]] (строка 2 использована
дважды, строка 1 — ни разу). Тест `TestEmbeddingScatterAdd`.

Это объясняет, почему эмбеддинги **редких** токенов учатся медленно: их градиент почти всегда ноль — и почему
важно, что AdamW (L3, 6.6) не «пережимает» их weight decay'ем.

### Проверка «loss на старте»

До обучения модель не знает ничего, распределение должно быть почти равномерным: P(любой символ) ≈ 1/V.
Значит, loss ≈ −ln(1/V) = **ln V = ln 56 ≈ 4.025**. У нас — 4.033 ✓. Если на старте loss намного больше — веса
выходного слоя слишком крупные и модель «уверенно ошибается»; поэтому `mlplm.NewModel` уменьшает W₂ в 10 раз.
Это первая проверка из «рецепта» Karpathy, и она — тест `TestMLPBeatsBigram`.

## 7. Реализация на Go

### 7.1. Тензорный autograd: все операции

Каждая операция — forward + backward по шаблону из L3. Все проверены `GradCheck` (тест `TestGradCheckOps`).

| Функция | Forward | Backward (что получает вход) |
|---|---|---|
| `Add(a, b)`, `Sub` | a ± b с broadcasting | ±g, суммированный по растянутым осям |
| `Mul(a, b)`, `Div` | поэлементно | g·b и g·a; g/b и −g·a/b² |
| `Scale(a, s)`, `Pow(a, p)` | s·a, aᵖ | s·g, p·aᵖ⁻¹·g |
| `MatMul(a, b)` | батч-matmul с broadcasting | g·bᵀ, aᵀ·g |
| `Exp, Log, Tanh, Sigmoid, ReLU, GELU, SiLU` | поэлементно | g · f'(x) |
| `Sum, Mean` | → скаляр (shape []) | g, растянутый на форму входа |
| `SumLast, MeanLast` | (…, n) → (…, 1) | g, растянутый по последней оси (для норм в L8) |
| `Reshape, Transpose` | view / копия | обратный reshape / transpose |
| `Embedding(W, ids)` | строки W → (len(ids), D) | scatter-add в строки W |
| `Softmax(a)` | по последней оси, стабильный | y ⊙ (g − Σ g⊙y) |
| `CrossEntropy(logits, targets)` | среднее −ln p_target; target < 0 игнорируется | (p − onehot)/N |
| `Dropout(a, p, rng)` | маска/(1 − p) | g ⊙ маска |
| `Const(c)`, `NewVar`, `Param`, `Detach` | константы, параметры, обрыв графа | |

Цикл обучения и конвенции API:

```go
// модуль = структура с параметрами + Forward + Parameters()
type Model struct {
	Emb    *nn.Embedding
	Hidden *nn.Linear
	Out    *nn.Linear
}

func (m *Model) Forward(ctx []int) *autograd.Var {
	b := len(ctx) / m.Cfg.Context
	x := m.Emb.Forward(ctx)                                // (B·N, D)
	x = autograd.Reshape(x, b, m.Cfg.Context*m.Cfg.EmbDim) // (B, N·D)
	h := autograd.Tanh(m.Hidden.Forward(x))                // (B, H)
	return m.Out.Forward(h)                                // (B, V)
}

func (m *Model) Parameters() []*autograd.Var { return nn.Collect(m.Emb, m.Hidden, m.Out) }
```

Обратите внимание на комментарии с формами в каждой строке — привычка из L1, которая спасает от половины багов.

## 8. Из продакшена

- **Инициализация в GPT-2 / nanoGPT:** все веса N(0, 0.02²), а выходные проекции residual-ветвей дополнительно
  делятся на √(2·L) (L — число слоёв), чтобы сумма вкладов всех слоёв в residual stream не росла с глубиной.
  Та же логика дисперсии, что в разделе 4.
- **Сломанная инициализация — тихий убийца.** Модель «учится», но медленно и хуже. Признаки: loss на старте ≫ ln V,
  гистограммы активаций прижаты к ±1 (tanh) или к 0 (ReLU), отношение ‖Δw‖/‖w‖ сильно отличается от ~10⁻³.
- **Почему GELU/SiLU, а не ReLU.** Меньше «мёртвых» нейронов и гладкий градиент. В Llama и большинстве современных
  LLM — **SwiGLU** (SiLU с «гейтом», L8).
- **FFN-блок трансформера — это ровно наш MLP** (Linear → GELU → Linear, ширина ×4), применённый к каждому токену.
  В больших моделях на FFN приходится ~⅔ всех параметров.
- **Переобучение в LLM-эпоху** проявляется иначе: при pretraining данных хватает, но при fine-tuning на тысячах
  примеров модель запоминает их за 2–3 эпохи. Поэтому SFT обычно 1–3 эпохи, с ранней остановкой по val loss (L13).
- **Производительность нашего Go-autograd** достаточна для моделей ~10⁴–10⁶ параметров. Основное время — matmul и
  выделение памяти под промежуточные тензоры; профилирование — задание ниже.

<details><summary>Ответы</summary>

1. Слой — m нейронов, веса которых сложены столбцами в матрицу W; все считаются одним XW + b.
2. (xW₁)W₂ = x(W₁W₂) — ассоциативность умножения матриц; композиция линейных функций линейна.
3. При |x| ≳ 2 производная tanh ≈ 1 − 1 = 0; по цепному правилу градиент через нейрон умножается на ≈ 0 и затухает.
4. Var(z) = n·σ²·v_x (каждое слагаемое имеет дисперсию σ²v_x, их n). ReLU обнуляет отрицательную половину,
   E[ReLU(z)²] = Var(z)/2, поэтому для сохранения сигнала нужно nσ² = 2.
5. Множитель ~nσ²/2 = 128 на слой → рост ~10²¹ в дисперсии (~10¹⁰ в std): взрыв, переполнение, бесполезные градиенты.
6. Train loss продолжает падать, val loss начинает расти. Больше данных, меньше модель, early stopping,
   weight decay, dropout.
7. Чтобы математическое ожидание активации не изменилось и на инференсе (без dropout) масштаб совпадал.
8. Lookup = one-hot·E, градиент попадает только в использованные строки и суммируется по повторам. Редкие токены
   получают градиент редко — их эмбеддинги учатся медленнее.
9. ≈ ln V: необученная модель даёт почти равномерное распределение, −ln(1/V) = ln V.
10. Контекст 3 даёт больше информации, чем 1 символ, при умеренном числе параметров. С контекстом 8 и ~38 тыс.
    параметров на 5 тыс. символов модель запоминает обучающий текст (train 0.12) и не обобщает (val 3.37).
