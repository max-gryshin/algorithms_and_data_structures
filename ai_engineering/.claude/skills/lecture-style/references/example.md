# Эталон: L03, раздел 3.2 «Градиент» (начало)

## До

```markdown
### 3.2. Градиент

### 🔍 Формула под лупой: градиент

$$\nabla f = \left( \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right)$$

| Символ | Как читать | Смысл |
|---|---|---|
| ∇f | «набла эф», «градиент эф» | вектор из всех частных производных |
| ∂f/∂xᵢ | частная производная по i-й переменной | чувствительность f к i-й «ручке» |

Для примера выше ∇f(2, 5) = (20, 7).

![Карта уровней f(x, y) = x²y + 3y и градиент в точке (2, 5)](img/L03_partial_contours.svg)

Это вид на ту же функцию сверху: каждая линия соединяет точки с одинаковым значением f, как горизонтали на
топографической карте. Синяя и оранжевая стрелки — шаги только по x и только по y, их «силу» задают частные
производные 20 и 7. Красная стрелка — градиент (20, 7): сумма этих двух направлений с весами 20 и 7. Он почти
горизонтален, потому что по x функция в ≈ 2.9 раза чувствительнее.

Ещё одно свойство видно на картинке: градиент **перпендикулярен** линии уровня f = 35. Проверим на числах. Линия
f = 35 — это y = 35/(x² + 3). Её наклон в x = 2: dy/dx = −2·35·x/(x² + 3)² = −140/49 ≈ −2.857, то есть
направление линии — (1, −2.857). Скалярное произведение с градиентом: 20·1 + 7·(−2.857) = 20 − 20 = **0**, значит
векторы перпендикулярны ✓. Вдоль линии уровня f не меняется, а быстрее всего f растёт поперёк неё.

**Главное свойство:** градиент указывает **направление наискорейшего роста** функции, а его длина — скорость
этого роста. Значит, **−∇f — направление наискорейшего убывания**. Отсюда весь метод градиентного спуска.
```

## После

```markdown
### 3.2. Градиент

### 🔍 Формула под лупой: градиент

У функции f(x, y) = x²y + 3y в точке (2, 5) мы уже знаем две частные производные: 20 по x и 7 по y.
Каждая отвечает на узкий вопрос: что будет с f, если двигать одну ручку, а другую держать. При обучении
мы двигаем все ручки сразу, поэтому удобно собрать все частные производные в один вектор:

$$\nabla f = \left( \frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_n} \right)$$

Значок ∇ читается «набла», а вся запись — «набла эф» или «градиент эф». На i-м месте стоит ∂f/∂xᵢ,
чувствительность f к i-й ручке. Для нашей функции получается ∇f(2, 5) = (20, 7): те же два числа,
записанные в одну строку. Пока это только удобная запись. Смысл у неё появляется, когда вектор рисуют.

![Карта уровней f(x, y) = x²y + 3y и градиент в точке (2, 5)](img/L03_partial_contours.svg)

Это вид на ту же функцию сверху. Каждая линия соединяет точки с одинаковым значением f, как горизонтали
на топографической карте. Синяя стрелка — шаг только по x, оранжевая — только по y, их длины задают
частные производные 20 и 7. Красная стрелка — сам градиент (20, 7), сумма двух шагов. Он почти
горизонтален: по x функция в ≈ 2.9 раза чувствительнее, и стрелка это показывает.

Присмотритесь, под каким углом красная стрелка пересекает линию f = 35. Похоже на прямой угол, и это можно
проверить. Линия f = 35 — это y = 35/(x² + 3). Её наклон в x = 2 равен
dy/dx = −2·35·x/(x² + 3)² = −140/49 ≈ −2.857, значит, линия идёт в направлении (1, −2.857). Скалярное
произведение с градиентом 20·1 + 7·(−2.857) = 20 − 20 = 0, векторы перпендикулярны ✓.

Почему так и должно быть? Вдоль линии уровня f не меняется совсем, это направление нулевого роста. Самый
быстрый рост естественно искать поперёк неё. Отсюда свойство, на котором держится весь градиентный спуск:
**градиент указывает направление наискорейшего роста функции**, а его длина равна скорости этого роста.
Значит, −∇f смотрит туда, где функция быстрее всего убывает. Пока мы приняли это по картинке; ниже
проверим на числах, сдвигаясь из одной точки в разные стороны.
```
